## 本轮修复

1. 录屏停止期间不得启动第二实例；启动失败清除空会话目录。
2. 超过 512 MiB 的上传明确失败，不再静默截断；上传与下载在创建目录前验证真实父路径，阻止符号链接越界副作用。
3. 支持小米 Android 16 的 `ResumedActivity:` 输出，恢复前台安全守卫链路。
4. UiAutomator 旧启动协程退出时不再覆盖新实例状态。
5. 已完成下载任务最多保留 256 条，避免常驻 Agent 内存无界增长。
6. Companion 补齐 Android 14+ `specialUse` 前台服务声明，Android 8+ 使用前台服务启动 API。
7. Companion 快速操作改为单线程串行并在销毁时清理；HTTP 响应限制 1 MiB，错误状态不再伪装成停止成功，连接始终释放。
8. Companion 包名、运行时长和节流边界与 Agent 合约一致。
9. 按 ATX 协议补齐 `GET/POST /shell/background` 与 `ANY /term`；增加命令/帧/并发限制、后台子进程回收和 PTY 断线清理。
10. Companion 增加运行中悬浮权限守卫；Android 16 撤权后 1 秒内停止服务并移除窗口。
11. Companion 建立五类统一尺寸规则，关闭控件使用固定 36/48dp 热区；性能、录制、Monkey、应用列表和最小化在 Android 12 完成视觉及交互复验，录制排除区与实际窗口复用同一尺寸来源。
12. Monkey 建立按目标包和设备本地时间隔离的证据包，包含结构化事件、最终清单、Activity 覆盖率及开始/结束/失败截图；状态接口补齐终止语义和产物索引，兼容日志按 32 MiB 单备份轮转。
13. 录屏改为按目标包、`ScreenRecord` 和设备本地时间归档；Monkey 与录屏每包每类型最多保留 200 个会话，避免长期运行无界占用存储。
14. Companion 增加平板统一尺寸档位；30714 在 Android 16 SM-X920 实测修正横屏性能窗偏小问题，紧凑面板统一为 320dp，关闭按钮、标题和正文同步放大，内容仍可滚动。

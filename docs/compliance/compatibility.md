# XTest 兼容矩阵

当前里程碑：M5.9 对齐收口。Nexus 77 个历史“方法+路径”合同已覆盖 77 个，逐项定义见[完整 HTTP 合同](http-contract.md)。HTTP 合同覆盖不代表全部设备与业务场景取得资格；Popup 差异见[专项审计](../audits/popup-alignment-audit.md)。任意 Shell 和 PTY 终端只在显式兼容开关下可用，默认部署仍拒绝访问。首次提交候选、许可证、第三方 NOTICE、敏感信息、大型二进制及发布前审查门禁已建立。

状态定义：`implemented` 已实现并有自动或真机证据；`qualified` 已实现明确的安全子集或兼容降级，限制已登记；`external-blocked` 实现验证需要当前环境没有的设备、可信二进制、后端或业务样本；`intentionally-disabled` 经安全决策不提供；`planned` 尚未进入生产代码。

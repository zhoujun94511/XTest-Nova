# ADR-0003：以显式开关提供 ATX 任意命令兼容

- 状态：已接受
- 日期：2026-09-04
- 取代：ADR-0002

## 决策

实现 Nexus/ATX 的 `GET/POST /shell/background` 与 `ANY /term`，并与现有 `/shell` 一起受 `-legacy-unsafe-api` 控制。默认不开启时三个入口固定返回 HTTP 403；配置仍默认只监听 `127.0.0.1`。

后台 Shell 接受 `command` 或 `c` 的查询、表单参数，并兼容 JSON，请求成功返回 `success`、`pid` 和 `description`。终端普通请求返回内嵌网页，WebSocket 保持 ATX 二进制协议：首字节 `0` 为终端输入，`1` 为 `{cols,rows}` 调整尺寸。

## 约束

- 后台命令不超过 16 KiB，同时运行不超过 16 个；Agent 持有并回收子进程句柄。
- PTY 帧不超过 64 KiB，同时会话不超过 4 个；断线时关闭 PTY 并终止、回收对应 shell。
- Web 资源内嵌且不依赖 CDN；终端页面沿用现有 CSP 边界。
- 此开关不等同于认证或授权。不得在非可信网络监听地址上启用。

## 理由

维护者明确要求与 ATX 原有能力对齐。显式兼容模式满足旧客户端合同，默认拒绝、回环监听和资源边界则避免改变常规部署的攻击面。

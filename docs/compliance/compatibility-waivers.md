# 兼容资格与豁免登记

本登记只解释已实现能力的明确限制，不允许用豁免掩盖崩溃、数据破坏、伪成功或安全边界绕过。每项必须满足解除条件后才能改为 `implemented`。

## 审批原则

- W-002 是安全设计决定，不以复刻旧版不安全行为为解除目标；
- W-003、W-007 必须如实暴露能力降级，客户端不得把普通 View FPS、`null` 或低帧率解释成所有渲染路径的完整能力；
- 所有外部二进制必须记录来源、许可证、版本和 SHA-256；
- 外部阻塞项不影响已验证安全子集，但不能在发布说明中宣传为完整兼容。

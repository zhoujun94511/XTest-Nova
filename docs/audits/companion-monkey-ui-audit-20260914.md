# Companion 智能遍历配置审计与整改（2026-09-14）

## 结论

旧界面把运行时长、动作间隔、低电量阈值和多组高级参数平铺为无单位输入框，Activity 范围还要求手工输入类名，容易产生错误配置。控件黑名单还存在语义偏差：页面中只要出现匹配文本，旧 Guard 就会返回整页，而不是只跳过该控件。

## 生命周期边界

```text
选择应用 -> 创建 MonkeyDraft -> 启动时生成 RunConfig
                              -> 应用内恢复/广告重启：沿用同一 RunConfig
                              -> Stop/到时结束：Runner 退出并释放配置
下一次选择应用 -> 新 MonkeyDraft（默认不限制、无临时规则）
```

`run.json` 可以记录本次配置作为审计证据，但它不会被读取为后续任务策略，也不代表永久生效。

# 游戏坐标证据与包体门禁整改 Todo

日期：2026-09-15

## 决策

依据整体成熟度审计和 Android 15/16 真机结果，本轮不实现完整的 SurfaceFlinger、截图差分、网格反馈探测架构。当前高优先级风险已有 bounded 默认值、安全触摸区、特殊页预检和安装/下载拦截保护；完整方案工作量和普通应用回归面明显高于现阶段收益。

本轮只实现两个低风险、高可验证收益项：

1. 为实际发生的游戏坐标动作补充坐标、归一化区域、来源、动作后特殊页/外跳结果及恢复耗时证据。
2. 为 Runner、两种 Agent 架构、Companion 和 runtime bundle 增加可执行的包体积门禁。

Runner 自测、Agent 全量测试、发布链校验及大小门禁正反向测试均已通过。新 Runner 已同步到四组件 runtime bundle 后重建 Agent，避免发布制品继续携带旧逻辑。

## 后续升级触发条件

只有正式 Android 13/15/16 各 20 分钟基线满足以下任一条件，才重新评审完整游戏探测方案：坐标动作外跳率超过 1%、连续 5 次无推进、单次卡住超过 30 秒、恢复/重复耗时超过任务 10%，或相同问题出现在至少两种渲染引擎。

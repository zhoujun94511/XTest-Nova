# Web 按钮布局与远控链路整改 Todo（2026-09-12）

## 审计结论

诊断页的 `.soak-panel` 被误加入通用横向 Flex 选择器，面板标题、表单、按钮和输出区因此成为同一伸缩容器的直接子项；在不同宽度和内容状态下，按钮会被剩余空间拉伸，看起来突然变大。该问题不是采样功能改变，而是业务组件与通用布局规则耦合。

Nova 后端已经具备官方 scrcpy 4.1 的 H.264 画面 WebSocket、独立控制 WebSocket、清晰度档位、触摸、滚动、按键、旋转、文字和剪贴板协议，但 Web 控制台没有入口和播放器，导致用户功能链路中断。参考项目的播放器依赖旧 React 页面和额外的 H.264 转换库，不适合直接复制到当前无外部 CDN 的原生控制台。

## 设计边界

远控仅在进入“远控”页面时建立视频和控制通道，不在控制台后台常驻，不加入会话轮询。当前依赖支持 WebCodecs 的现代 Chromium 浏览器；不支持时页面会明确显示解码能力错误，不会退化为高频截图轮询。scrcpy server 仍是项目已固定哈希并登记许可证的官方运行载荷，本轮没有新增第三方库或联网资源。

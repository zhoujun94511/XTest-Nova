# M4.1 录制回放验证记录

验证日期：2026-09-03  
验证设备：Xiaomi 2510DPC44G，Android 16 / API 36，ARM64  
目标：建立可维护的单指录制、标准化用例和受限确定性回放基础链。

## 已完成

- 将既有 Protocol-B TouchReader 提取为可复用捕获源，WebSocket 兼容入口保持不变；
- 原始 down/move/up 触点按距离和持续时间归并为点击、长按和滑动；
- 坐标保存为 `0..1` 百分比，并记录录制时显示尺寸；
- 建立 `xtest-recording/v1` 用例、单调时间轴、10000 动作上限和 24 小时时长边界；
- 当时用例以临时文件加原子重命名方式保存到 `/sdcard/XTestNova/<包名>/Replay/<UTC时间>/case.json`；30708 起新产物已迁移为 `/sdcard/xtest-nexus/<目标包名>/Replay/<UTC时间>/case.json`；
- SHA-256 摘要覆盖元数据和动作，时间统一到 UTC 毫秒、空动作统一为空数组，确保不同 JSON 客户端语义一致；
- 回放支持点击、长按、滑动和返回键，其他按键、未知动作、非法坐标或篡改摘要会被拒绝；
- 回放必须显式设置 `execute=true`，每个动作前重新检查目标应用处于前台；
- 回放使用绝对动作起始时间轴，速度范围为 `0.1..4`；
- 录制、回放、随机 Runner 和智能遍历互斥；停止接口使用同一执行锁完成状态切换；
- 新增只校验不执行的 `POST /v1/replays/validate`。

## 当前边界

M4.1 不宣称支持文本、双击语义、多指手势、截图断言、循环和中断组合。真实有动作的端到端回放应由用户选定无破坏测试页面后专项执行；本轮只证明捕获、保存、跨客户端校验和零动作生命周期，不以空回放冒充业务动作通过。

# ADR-0001：采用行为兼容重写

- 状态：已接受
- 日期：2026-09-03

## 决策

Nova 采用行为兼容重写。Nexus 的公开协议、测试记录和可读 Go 实现用于确定合同；反编译 DEX/Smali 只作为人工分析证据，不进入 Nova 生产源码或构建链。

保留 ATX/XTest 的设备侧 Agent 思路，但不重新从已归档的上游 `atx-agent` 建立分支。UiAutomator 等活跃组件以适配器方式接入。

## 原因

- 全量反编译恢复无法可靠重建命名、注释、并发意图和异常边界；
- Android shell UID 能力与普通 APK 能力不同，需要明确进程隔离；
- 当前 Nexus 已经提供足够的外部合同，可支持黑盒等价验证；
- 分层重写允许旧、新引擎并行验证和逐步切换。

## 后果

- 首期不会立即覆盖全部历史功能；
- 每个迁移能力需要合同测试和真机证据；
- 新内部模型可以演进，历史兼容只存在于 adapter 层。

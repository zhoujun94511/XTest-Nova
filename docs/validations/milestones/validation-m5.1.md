## Android 16 部署演练

在同一设备完成完整版本往返：

1. 暂存上传、远端哈希核验并启动 M5.1，健康版本为 `xtest-nova-0.13.0-m5.1`；
2. 显式回滚，恢复后的健康版本为 `xtest-nova-0.12.0-m4.4`；
3. 再次部署 M5.1，健康版本重新变为 `xtest-nova-0.13.0-m5.1`；
4. 测试结束后停止 Agent 并清理本轮端口转发。

另使用主机 TCP 监听器占用指定转发端口，主动制造启动后健康检查前的部署失败。部署器检测到 ADB 无法绑定端口后进入自动恢复；远端 Agent 哈希恢复为切换前版本，Agent 保持停止，未遗留转发。故障注入门禁通过。

# ADR-0002：不实现无认证后台 Shell

- 状态：已被 ADR-0003 取代
- 日期：2026-09-03

## 决策

保留历史 `/shell/background` 路由用于能力探测，但固定返回 HTTP 403。Nova 不在无认证的 7912 管理端口提供任意 `sh -c` 后台执行。

后续后台能力使用有类型的任务模型，例如性能采样、Monkey、录屏和日志采集。每种任务拥有独立参数校验、状态、停止和日志策略。

## 原因

历史接口允许调用方以 Android shell 权限执行任意命令，能够删除设备文件、读取敏感信息或中断系统服务。仅使用启动参数开启仍不能提供调用方身份验证和操作审计。

如果未来必须提供通用远程命令，需要单独设计认证、授权、审计、命令范围和部署网络边界。

2026-09-04 根据兼容要求改为“默认关闭、显式开关启用”，详见 ADR-0003。默认部署的拒绝策略不变。
